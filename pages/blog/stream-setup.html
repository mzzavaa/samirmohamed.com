Built a Stream Setup. Open-Sourced It.

Apr 01, 2026 · 2 min read

📦 Repo: community-gameday-europe-stream-templates

Community events need streaming. Pro equipment costs a fortune. So I built something cheaper.

The Stack

  • OBS for the actual streaming
  • NDI for camera feeds over network
  • Python scripts for scene switching
  • Some cheap HDMI capture cards

Total cost: maybe €500 in hardware. Rest is free software.

Why Bother

Rented streaming setups cost €2-3k per day. That's insane for a community meetup with 50 people.

This setup runs the whole thing with one laptop and some cables.

The Hard Part

Audio. Always audio. Spent more time debugging audio sync than everything else combined.

Solution: dedicated audio interface. Don't try to capture audio through HDMI. Just don't.

Using It

Ran it at a few community events now. Works fine. Quality is good enough for YouTube.

Not broadcast quality, but nobody cares. People just want to see the slides and hear the speaker.

Code's on GitHub if you want it.
